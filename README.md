# Dr. Shivani and Dr. Abhijit Wedding Invitation

A bilingual English and Marathi wedding invitation website.

## Live website

[View the live website](https://pvaishnavi01-do.github.io/Shivani-Abhijit-Wedding)

## Project structure

- `html/index.html` - invitation page
- `css/styles.css` - styles and responsive layout
- `js/data.js` - wedding date and celebration schedule
- `js/script.js` - countdown, language switching, music, and interactions
- `assets/` - images and fonts
- `.github/workflows/deploy-pages.yml` - GitHub Pages deployment workflow

## Local preview

Open `html/index.html` directly in a browser, or serve the project locally:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000/html/`.

## Deployment

The site deploys automatically to GitHub Pages whenever changes are pushed to the `main` branch.
